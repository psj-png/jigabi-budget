# 계산 규칙

금액은 원 단위 정수다. 사고 싶은 것은 여유 돈에서만 나가고, 최소 생활비는 앱이 먼저 줄이지 않는다.

## 용어

| 용어 | 뜻 |
| --- | --- |
| 기간 | 기간 기준 수입일(예: 알바비 25일)부터 다음 수입일 전날까지 |
| 쓸 수 있는 돈 | 기간 시작 잔액 + 기간 안에 들어올 다른 수입 |
| 최소 생활비 | 밖에서 먹는 끼니 + 그날 가는 곳의 왕복 교통비. 집에서 먹는 끼니는 0원 |
| 여유 돈 | 쓸 수 있는 돈 − 고정지출 − 약속 − 최소 생활비 − 이번 기간에 갚을 비상금 |
| 남은 날 | 오늘부터 기간 끝까지. 오늘 밤 잔액을 기록했으면 내일부터 |
| 하루 여유 | 여유 돈 ÷ 남은 날 (100원 아래 버림) |
| 넉넉 기준 | 사용자가 정하는 값, 기본 10,000원. 지갑이 단계를 정함 |

## 규칙

| # | 규칙 | 계산 |
| --- | --- | --- |
| R1 | 기간 | 기간 기준 수입일부터 다음 수입일 전날까지. 첫 기간은 앱을 시작한 날부터, 새 기간은 수입일 밤 잔액으로 시작 |
| R2 | 쓸 수 있는 돈 | 기간 시작 잔액 + 기간 안에 들어올 다른 수입. 비상금은 넣지 않음 |
| R3 | 그날 최소 생활비 | 그날 가는 곳마다 (거기서 먹는 끼니 수 × 끼니 가격 + 왕복 교통비)를 더함. 집에서 먹는 끼니는 0원 |
| R3-1 | 끼니 | 끼니 수와 가격은 가는 곳마다 정함. 식사가 나오는 알바는 0원. 자취면 장보기 주 단위 ÷ 7을 매일 더함 |
| R3-2 | 그날 가는 곳 | 요일이 맞고 시작일~끝나는 날 안인 곳만. 교통 정기권이면 교통비 0, 정기권 값은 고정지출 |
| R4 | 최소 생활비 | 남은 날의 R3 합 |
| R5 | 여유 돈 | 쓸 수 있는 돈 − 고정지출 − 남은 약속(교통비 포함) − 최소 생활비 − 이번 기간에 갚을 비상금 |
| R6 | 하루 여유 | 여유 돈 ÷ 남은 날, 100원 아래 버림 |
| R7 | 오늘 쓸 수 있는 돈 | 오늘의 R3 + R6 + 오늘 약속 금액(교통비 포함) |
| R8 | 지갑이 단계 | 하루 여유를 넉넉 기준과 비교: 넉넉 기준 이상 빵빵, 절반 이상 든든, 10분의 1 이상 홀쭉, 0 이상 텅텅, 0 미만 나방 |
| R9 | 약속 교통비 | 그날 가는 곳이 없으면 교통비 체크를 켜고, 있으면 끈 채로 시작 |
| R10 | 밤 잔액 | 쓴 돈 = 지난 잔액 + 들어온 돈 − 빠져나간 고정지출 − 기록한 구매 − 지금 잔액. 여유 돈에서 (쓴 돈 − 그 사이 최소 생활비 합 − 그 사이 약속 합)을 뺌. 빼먹은 날은 합쳐서 계산하고, 수입일엔 실제 들어온 금액을 확인 |
| R11 | 미리보기 | 고른 물건 값 합 P를 빼고 R5~R8을 다시 계산. 0 미만이면 "최소 생활비를 X원 건드려요". 알바 시간 = P ÷ 시급, 반올림 |
| R12 | 잔액 확인 | 오늘 잔액 − P에서 날짜순으로 수입은 더하고 고정지출·최소 생활비·약속은 빼 감. 0 아래로 가는 날이 있으면 그 뒤 첫 수입일에 사라고 권함 |
| R13 | 나눠 사기 | 물건마다 이번·다음·그다음 기간 중 하나에 넣는 경우를 모두 따져서 ① 나방 없음, 필요한 날 전에 사기 ② 모든 기간이 홀쭉 이상 ③ 더 일찍 사는 쪽 ④ 가장 빠듯한 기간이 덜 빠듯한 쪽 순으로 고름. 다음 기간은 예상 수입 기준, 이번 기간에서 남는 돈은 0으로 봄 |
| R14 | 다시 짜기 | 산 뒤 여유 돈이 0 미만이면 반품(받은 날 빼고 7일) → 약속 줄이기 → 비상금에서 빌리고 다음 기간에 나눠 갚기 순으로 메움. 그래도 남으면 최소 생활비를 줄일지, 알바를 더 할지 사용자가 고름 |
| R15 | 시작 경고 | 고정지출 + 약속 + 최소 생활비가 쓸 수 있는 돈보다 크면 "아무것도 안 사도 모자라요" |

체크카드와 계좌이체만 다룬다. 월세·기숙사비·학비는 따로 다루지 않고, 직접 내는 사람은 고정지출에 넣는다.

## 확인용 예시

`db/seed.sql`의 예시 사람이다. 계산 코드를 고치면 아래 숫자가 그대로 나오는지 확인한다.

'10/30 밤 5,800원 쓴 뒤' 줄을 빼면 모두 10/30 밤 잔액을 기록하기 전 기준이다 (남은 날 26일). seed에는 10/30 밤 잔액이 들어 있으므로, 테스트할 때는 이 기록을 빼고 계산한다.

- 오늘 2026-10-30(금), 잔액 290,000원. 기간은 10/30~11/24(26일)
- 학교: 월~목, 9/1~12/18, 학식 2끼 × 6,000원, 왕복 3,100원
- 알바: 토·일, 왕복 3,100원, 끼니는 집에서
- 용돈 매달 1일 250,000원, 알바비 매달 25일 420,000원
- 고정지출 43,900원(통신비 5일, 음악 구독 12일), 11/7 술자리 30,000원, 비상금 100,000원

| 항목 | 기대값 |
| --- | --- |
| 최소 생활비 | 236,200 (학교 14일 × 15,100 + 알바 8일 × 3,100 + 그 외 4일 × 0) |
| 쓸 수 있는 돈 | 540,000 |
| 여유 돈 / 하루 여유 | 229,900 / 8,800 (든든) |
| 오늘 쓸 수 있는 돈 | 금 8,800 · 토 11,900 · 월 23,900 · 11/7 41,900 |
| 10/30 밤 5,800원 쓴 뒤 | 여유 돈 224,100, 하루 여유 8,900 |
| 미리보기 (하나씩) | 롱패딩 1,500 홀쭉 · 니트 6,900 든든 · 목도리 7,700 든든 · 부츠 4,200 홀쭉 |
| 미리보기 (4개 다, 386,000) | 나방, 최소 생활비 156,100원 침범, 알바 약 37시간 |
| 나눠 사기 | 지금 니트·목도리·부츠 → 이번 기간 1,200 홀쭉 / 11/25 롱패딩 → 다음 기간 6,600 든든 |
| 다음 기간 (11/25~12/24) | 여유 돈 389,900, 하루 여유 12,900 |
| 다시 짜기 (3개 267,000 구매) | −37,100 → 술자리 3만→2만 → 비상금 27,100, 다음 기간 하루 여유 12,900 → 12,000 |
| 약속 추가 (11/13 금 50,000 + 교통 3,100) | 하루 여유 8,800 → 6,800 |
| 잔액 확인 (다른 사람: 잔액 50,000, 11/1 용돈 500,000, 10/30에 49,000 구매) | 10/31 잔액 −2,100 → "11/1 용돈 들어온 뒤에 사기" |
